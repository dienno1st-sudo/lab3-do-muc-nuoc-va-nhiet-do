Cấu hình kết nối MQTT

Cấu hình mặc định khớp code ESP32 đã gửi. Khi đổi topic, sửa cả trong HTML và sketch. Cần Internet để tải thư viện MQTT.js và kết nối broker.

Hướng dẫn chạy & quy tắc điều khiển
  1. Chạy sơ đồ Wokwi với code ESP32 đã có. Chờ Serial báo [MQTT core 0] Connected.
  2. Mở file HTML này bằng Chrome/Edge rồi bấm Kết nối MQTT. Không cần cài web server.
  3. Thay đổi khoảng cách trên HC-SR04 hoặc nhiệt độ trên DS18B20 trong Wokwi; số và hai biểu đồ sẽ cập nhật.
  4. Hai nút bơm/van gửi lệnh manual. Nút Chuyển tự động gửi lệnh AUTO.

Vùng còn lạiDừng khi không có chu kỳ đang chạy

Code ESP32 chạy một chu kỳ cho mỗi vùng; đổi sang vùng khác để kích lại. Trang web chỉ gửi lệnh và hiển thị dữ liệu; ESP32 thực hiện luật tự động. Hai biểu đồ giữ tối đa 60 mẫu trong phiên mở trang.

Cách hiểu mực nước: bộ code hiện gửi khoảng cách d từ cảm biến đến mặt nước, không phải chiều cao nước h. Muốn tính h cần biết độ cao lắp cảm biến H và dùng h = H − d.

JSON nhận: distance_m, temperature_c, pump_percent, valve_open, mode, sample_ms. Lệnh gửi: PUMP_ON / PUMP_OFF / VALVE_ON / VALVE_OFF / AUTO. Kết nối thành công với broker chưa có nghĩa ESP32 đã online; cần nhận được bản tin dữ liệu.

Broker công cộng dùng cho bài thực hành và dữ liệu mô phỏng; không gửi thông tin riêng tư. Sau 10 giây không có phản hồi mới, nút điều khiển sẽ tạm khóa. Web không tự gửi lệnh tắt khi mất kết nối.

Tham khảo: MQTT.js · HiveMQ broker.
